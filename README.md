# SK Free Toolkit

Daily apps for a productive life. Free to use, no login, works without internet after the first open.
Created by SK Free Toolkit. Made by Sunil Kumar P.

## Apps
- To-Do List (`todo/`)

## Put it online with GitHub Pages (about 5 minutes)
1. On github.com, create a new repository named `sk-apps` and set it to Public.
2. Click Add file, then Upload files. Drag in everything from inside this folder
   (index.html, manifest.webmanifest, sw.js, .nojekyll, LICENSE, README.md and the `icons` and `todo` folders).
   Keep the folders as they are. Click Commit changes.
3. Open Settings, then Pages. Under Branch choose `main` and folder `/ (root)`, then Save.
4. After about a minute the link appears: https://YOUR-GITHUB-NAME.github.io/sk-apps/
5. Open the link on your phone and choose Add to Home screen from the browser menu.

## Adding a new app later
Create a new folder, for example `bible/`, put its index.html inside, add a card for it in the
home page `index.html`, and add its files to the list in `sw.js` (then change VERSION, for example to skft-v2).

## Support
Add your UPI ID and QR code in the "Support this work" section of `index.html`.
